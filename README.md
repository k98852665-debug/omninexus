# OmniNexus

واجهة عربية متجاوبة لمشروع OmniNexus v11، مع محادثة وقسم لتنزيل جميع ملفات المشروع.

## التشغيل

يتطلب Python 3.12:

```sh
pip install -r requirements.txt
python OMNI_NEXUS_v11.py
```

افتح http://localhost:8000. للنشر استخدم إعداد Render المجاني في render.yaml.

## وظائف النسخة

- واجهة عربية متجاوبة، إدخال عربي وإنجليزي، وحالات اتصال وانتظار وأخطاء.
- واجهات المحادثة REST وWebSocket الأصلية، مع تحديد طول الإدخال.
- ملفات المشروع الأصلية والتحديثات، وتنزيل المشروع بصيغة ZIP.
- فصل ذاكرة المحادثة بين جلسات المتصفح باستخدام ملف ارتباط موقّع.

## حدود النسخة

المحرك الأصلي ينتج ردودًا برمجية تجريبية، ولا يتصل بنموذج لغوي حقيقي. أدوات البحث وفحص المنافذ وWHOIS تعرض نتائج تجريبية؛ لا تنفذ فحصًا حقيقيًا. الاستدلال والتقييمات داخل المحرك محاكاة. تغيير الواجهة لا يغيّر هذه الحقيقة.

لا يحتاج التشغيل الافتراضي إلى مفاتيح API أو تنزيل نماذج لغوية. تحليل الإنجليزية مبسط، ويمكن تفعيل embeddings اختياريًا عبر NEXUS_EMBEDDINGS=1 بعد تثبيت sentence-transformers في بيئة ذات ذاكرة مناسبة.

ذاكرة SQLite مؤقتة على استضافة Render المجانية، وتُفقد عند إعادة تشغيل الخدمة. هذه نسخة تجريبية وليست خدمة ذكاء اصطناعي للإنتاج. «محادثة جديدة» يمسح الرسائل المعروضة فقط.
