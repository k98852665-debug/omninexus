# OmniNexus

موقع محادثة عربي متجاوب، مرتبط بنموذج GPT-OSS 120B عبر Groq، مع تنزيل ملفات المشروع كاملة.

## التشغيل

يتطلب Python 3.12. ثبّت المتطلبات ثم اضبط متغير البيئة GROQ_API_KEY وشغّل:

```sh
pip install -r requirements.txt
python OMNI_NEXUS_v11.py
```

افتح http://localhost:8000. ملف .env.example مثال فقط؛ التطبيق يقرأ متغيرات البيئة الفعلية ولا يحمّل ملف .env تلقائيًا.

## الربط المجاني

- أنشئ حسابًا على https://console.groq.com واختر Free؛ لا تفعّل الفوترة أو خطة Developer.
- أنشئ مفتاحًا خاصًا بالموقع، وأضفه إلى Render → omninexus → Environment باسم GROQ_API_KEY.
- احفظ الإعدادات وأعد النشر. لا تضع المفتاح في GitHub أو ملفات المشروع أو رسائل المحادثة.
- النموذج المستخدم: openai/gpt-oss-120b. يمكن أن تتغير النماذج والحصص المجانية لدى المزوّد.
- عند غياب المفتاح تتوقف المحادثة مع حالة واضحة، وتظل الملفات متاحة. لا يتم الرجوع إلى ردود المحاكاة.

## المحادثة والخصوصية

تُرسل الرسالة وآخر جزء محدود من المحادثة إلى Groq لإنشاء الرد. لا توجد أدوات تصفح أو تنفيذ أو قراءة ملفات مفعّلة للنموذج. لا يمثل هذا النموذج ChatGPT أو النموذج المستخدم داخل Codex.

السياق منفصل لكل جلسة متصفح بملف ارتباط موقّع. تُحفظ آخر 6 جولات في ذاكرة الخادم لمدة تصل إلى ساعة، بحد أقصى 128 جلسة؛ «محادثة جديدة» يمسح هذا السياق. يحتفظ الطلب بسياق محدود يناسب الحصة المجانية. الذاكرة تُفقد عند إعادة تشغيل الخادم.

يحمي التطبيق الحصة بحد محلي قدره 10 طلبات في الدقيقة و300 طلب يوميًا لكل عملية خادم، إضافة إلى حدود Groq الفعلية. هذه الحدود المحلية تُصفّر عند إعادة التشغيل ولا تغني عن إبقاء حساب Groq على Free. لا يوجد تحويل تلقائي لخطة مدفوعة.

الكود التجريبي الأصلي محفوظ في OMNI_NEXUS_v11.py للتوافق، لكنه لا يُستخدم لإنشاء إجابات المحادثة. مسارات /tool القديمة ما زالت محاكاة موسومة بأنها demo.
